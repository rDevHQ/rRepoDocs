# Repository agent instructions

## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues for `rDevHQ/rRepoDocs`. Before issue operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triage or label operations, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase, read `docs/agents/domain.md`.
